# Cyber Attack Earth — Escalation Atlas

Publicly documented cyber incidents from 2000 to today, from five independent incident
sources plus vulnerability and advisory context, on a globe you can play through time.

**Live:** https://stuartokin.github.io/cyber-attack-earth/

- The data pack in `cyber_data/` is rebuilt automatically (fast sources nightly, everything
  weekly) by `build_cyber_data.py` in GitHub Actions.
- Disclosed incidents are a small, uneven fraction of what happens; the page says so, and
  labels attacker claims, provisional coding and modelled figures as such.
- Sources and licences: [`ATTRIBUTION.md`](ATTRIBUTION.md). Operating guide:
  [`MAINTENANCE.md`](MAINTENANCE.md). How it works: [`docs/HANDOVER.md`](docs/HANDOVER.md).
  Tests: [`tests/README.md`](tests/README.md).

organisation I am engaged with.
